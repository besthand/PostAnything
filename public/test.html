HTTP Relay — Self Test

這個頁面讓 AI Agent 不依賴任何外部服務，就能端到端驗證 Relay 是否正常運作。

Echo Endpoint

COPY_STATUS: IDLE

Steps
  1. 開啟 Relay Page（/），確認頁面顯示 TOKEN: LOADED。
  2. Method 選 POST。
  3. URL 貼上本頁的 ECHO URL。
  4. Query Parameters 新增一組：Key probe、Value relay-selftest。
  5. Headers 新增一組：Header X-Probe、Value relay-selftest。
  6. Body Type 選 JSON，Body 填 {"probe":"relay-selftest"}。
  7. 按 SEND REQUEST，等 HTTP RESPONSE 區出現結果。
  8. 確認 STATUS: SUCCESS、HTTP_STATUS: 200，且 RESPONSE_BODY 內同時出現 "probe":"relay-selftest"（query）、 "x-probe":"relay-selftest"（header）、 以及 body 原文。三者都對上就代表整條路徑正常。
Notes
  • Echo 端點與 Relay 同源，因此必須把這個部署的網域加進 ALLOWED_HOSTS，或設定 ALLOW_ANY_PUBLIC_HOST=true， 否則會得到 HOST_NOT_ALLOWED。
  • 在本機用 localhost 測試時會被 SSRF loopback 規則擋下並回 SSRF_BLOCKED。這是刻意保留的行為 — allowlist 與 SSRF 是兩道獨立防線。 本機自我驗證請改用可公開解析的網域。
  • /api/echo 不需要 Relay Token，它的角色是「被 Relay 呼叫的目標」。
