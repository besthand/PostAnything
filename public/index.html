HOW TO USE（AI AGENT 操作指南）
  1. 確認上方顯示 TOKEN: LOADED。若顯示 TOKEN: NOT LOADED，改用網址 #token=<RELAY_TOKEN> 重新開啟本頁。
  2. Method 選單選擇 HTTP Method（GET / POST / PUT / PATCH / DELETE 等）。
  3. URL 欄位輸入完整目標網址（含 https://），不需要自己做 URL encoding。
  4. 需要 Query Parameter 時按 ADD PARAMETER，逐組填 Key 與 Value。
  5. 需要自訂 HTTP Header 時按 ADD HEADER，逐組填 Header 名稱與 Value。
  6. Body Type 選 none / JSON / raw / application/x-www-form-urlencoded；選 JSON 或 raw 時在下方 textarea 填內容，選 form 時改用 ADD FORM FIELD 逐欄填寫。
  7. 不確定內容是否正確時，先按 SHOW REQUEST PREVIEW 檢查（Authorization 等敏感 Header 只在預覽中顯示為 ********，實際送出時仍是完整值）。
  8. 按 SEND REQUEST 送出。按鈕會變成 SENDING...，等它變回 SEND REQUEST 代表已完成，再往下讀 HTTP RESPONSE 區塊。
  9. 判讀 HTTP RESPONSE：
    • STATUS: SUCCESS — Relay 已成功送出請求，接著看 HTTP_STATUS 判斷目標服務的結果（目標回傳 4xx/5xx 也算 Relay 成功，不是 Relay 錯誤）。
    • STATUS: ERROR — Relay 本身拒絕或失敗，看 ERROR_CODE： INVALID_RELAY_TOKEN（token 沒帶到或錯誤，需重新用 #token= 開頁）、 HOST_NOT_ALLOWED（目標網域不在管理者設定的白名單）、 SSRF_BLOCKED（目標指向內部網路，不要重試）、 METHOD_NOT_ALLOWED（換一個被允許的 Method）、 TARGET_TIMEOUT（目標沒回應，可稍後重試）、 RATE_LIMITED（送太快，等一分鐘再試）。
  10. 不確定 Relay 是否正常運作，可到 /test.html 用內建的 Echo Endpoint 做一次端到端自我驗證。
